Project: Preventify - clinical live-assist tool for doctors/nurses.

Current state (as of 2026-02-02):
- Steps 1-5 of plan.txt complete.
- Monorepo scaffolded with apps (backend, desktop, mobile) and packages (shared).
- Backend: Fastify + TypeScript with Firebase Admin SDK, auth middleware, RBAC.
- Desktop frontend: Vite + React with Firebase Auth (Google + email/password), syncs user to backend on login.
- Auth flow: Firebase ID tokens verified server-side; roles stored as custom claims.
- Roles defined: doctor, nurse, admin. Default role for new users is doctor.
- API endpoints: health check, auth/login, auth/me, admin/users, admin/users/:uid/role.

Core workflow (not yet implemented):
- Live consult audio -> transcript -> local LLM suggestions/questions -> final summary/diagnosis.

Platforms:
- React Native for iOS/Android (scaffolded, not built out).
- React for desktop (auth + health check working).

Tech stack:
- Backend: Node.js (Fastify + TypeScript).
- Database/Auth: Firebase (Firestore + Firebase Auth).
- n8n: intended for automation workflows (not yet integrated).

Key constraints:
- Secrets must live in root `.env` file; never hardcode secrets.
- Vite desktop app reads env vars from root `.env` via `envDir` config.

Open decisions:
- STT provider (local vs cloud).
- LLM runtime (local model, hardware targets).
- Real-time transport (WebSocket vs SSE).
