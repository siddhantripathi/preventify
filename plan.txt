Preventify Development Plan (Technical, Atomic)

1) Repository and Workspace Setup
1.1 Create monorepo root with separate apps and packages.
1.2 Add root `.gitignore`.
1.3 Add root `.editorconfig`.
1.4 Add root `.env` placeholder and `.env.example`.
1.5 Define environment variable naming conventions.
1.6 Create `apps/mobile` for React Native.
1.7 Create `apps/desktop` for React.
1.8 Create `apps/backend` for API.
1.9 Create `packages/shared` for types and utilities.
1.10 Add root README with run scripts.

2) Tooling and Quality Gates
2.1 Add TypeScript configuration for all apps.
2.2 Add ESLint configuration and shared rules.
2.3 Add Prettier configuration.
2.4 Add lint scripts in each app.
2.5 Add test runner selection (Jest/Vitest).
2.6 Add commit hooks (lint-staged, husky).
2.7 Add CI pipeline for lint/test/build.

3) Backend Scaffolding
3.1 Choose backend runtime (Node.js or Python).
3.2 Scaffold API server project.
3.3 Configure environment loader to read root `.env`.
3.4 Add config module for environment validation.
3.5 Set up request logging middleware.
3.6 Set up error handling middleware.
3.7 Add health check endpoint.

4) Database and Migrations
4.1 Choose database (PostgreSQL).
4.2 Choose ORM or query builder.
4.3 Set up migration tooling.
4.4 Create initial migration table.
4.5 Define DB connection pool.
4.6 Add DB health check.

5) Auth and RBAC
5.1 Define roles: doctor, nurse, admin.
5.2 Implement user model and migration.
5.3 Implement password hashing or SSO placeholder.
5.4 Implement login endpoint.
5.5 Implement JWT issuance and refresh.
5.6 Implement auth middleware.
5.7 Implement RBAC guard utilities.
